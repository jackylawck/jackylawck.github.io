## 🎯 Overview & Decoupled Architecture (項目概述與分層管治架構)

- **繁體中文**：本倉庫託管羅子淇的官方個人主頁，展示其在**人力資本轉型**、**代碼即管治 (Governance-as-Code)**、**零信任隱私架構**、**跨學科數值模擬**以及**企業級 AI 與低代碼自動化管治**領域的戰略實踐。全站採用「前後台分層治理（Decoupled Presentation & Indexing）」設計，恪守零追蹤、零依賴與純前端記憶體運算原則。
- **English**: This repository hosts the official landing hub of Jacky Law, showcasing strategic initiatives across **Workforce Transformation**, **Governance-as-Code**, **Zero-Trust / Zero Data Retention (ZDR) architectures**, **computational research**, and **enterprise AI, automation & low-code governance**. It implements a decoupled presentation and indexing architecture adhering to zero-telemetry and pure client-side execution principles.

### 📂 Repository Structure (核心檔案分工)
- `index.html` — **Executive Landing Portal (高管極簡門面)**：聚焦最具董事會說服力與商業落地價值的 7 大核心企業合規與 AI 管治原型，內嵌 `Schema.org` 結構化數據與嚴格 CSP 策略。
- `llms.txt` — **Machine-Readable Governance Documentation (機器可讀管治文檔)**：對齊 IAPP AIGP 透明度框架，為大模型與 AI 搜尋代理提供完整的繁英雙語履歷、五大支柱清單及負向合規排除聲明（Out-of-Scope Assertions）。
- `sitemap.xml` & `robots.txt` — **Multi-Node Indexing & Crawler Governance (多節點索引與爬蟲治理)**：收錄全網域 48 個靜態應用入口，並依 RFC 9309 精準區分即時檢索代理（GEO/AIO）與無差別批量訓練爬蟲。
- `js/magi.js` — **Client-Side Governance Terminal (本機管治審計終端)**：純前端 DevTools 互動審計與三道防線（The Three Lines Model）自檢模組。

## 🛡️ Architecture & Hardened Security (架構與資安規範)

- **Pure Client-Side In-Memory Execution**: 無遠端資料庫、無伺服器端追蹤、零分析 Cookie，落實純記憶體即用即棄（Zero Data Retention）。
- **Strict Content Security Policy (CSP)**: 配置嚴格 HTTP 防護標頭（`object-src 'none'`、`form-action 'none'`），阻絕跨站腳本攻擊（XSS）與未授權資料外洩。
- **Cryptographic Provenance**: 正式發布 Commit 均經 PGP 金鑰（ID: `FFA3E47793F1CA32`）簽章，並具備 Keybase 跨平台身分存證。
